# Stages (project log, German)

One file per stage of the plan in [../PLAN.md](../PLAN.md), written in German. Each file has the
same sections:

| German heading | Meaning |
|---|---|
| Ziel, Voraussetzung | goal and prerequisites |
| Aufgaben | tasks, ticked when done |
| Abnahme | acceptance checks, ticked only when demonstrated |
| Nicht in dieser Stufe | explicitly out of scope |
| Der Mensch prüft danach | checks left to the maintainer |
| Ergebnis | result: what was built and actually checked, what is unchecked, what waits (*Wartet auf*) |

"Der Mensch" is the maintainer. Numbers such as 0035 refer to [../decisions/](../decisions/).
See [../README.md](../README.md) for how the documentation is organised.
