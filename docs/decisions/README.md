# Decisions (project log, German)

Recorded decisions, numbered in the order they were made (`NNNN-title.md`), written in German.
Each one gives the date, the reason (*Anlass*), the status, the affected code and, where it
applies, measurements. A decision is not rewritten afterwards: later changes are added as a dated
addendum (*Nachtrag*) or a new decision that refers to it.

The current state of the architecture that results from them is summarised in
[../ARCHITECTURE.md](../ARCHITECTURE.md). See [../README.md](../README.md) for how the
documentation is organised, and [../../CONTRIBUTING.md](../../CONTRIBUTING.md) for how to add a
decision.
